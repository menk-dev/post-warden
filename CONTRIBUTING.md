# Contributing

Read [AGENTS.md](AGENTS.md) for coding conventions and [dev/README.md](dev/README.md)
for checks. Discuss public API and delivery-semantics changes before implementing
them. Include tests for behavior and failures, and document guarantees precisely.

Use a feature branch and a pull request with a scoped Conventional Commit title
and explanatory body. Required CI checks must pass before merging. Never commit
broker credentials or production message contents.
